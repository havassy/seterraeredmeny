# Seterra eredményértékelő

Egyszerű, böngészőben futó webalkalmazás Seterra térképi kvízek eredményeinek gyors, egységes értékelésére.

A program a Seterra pontossági eredményét a megadott referenciaidőhöz viszonyított teljesítménnyel korrigálja. A gyorsabb megoldás javítja, a lassabb csökkenti az eredményt; a végső érték mindig 0 és 100% közé esik.

Fő funkciók:

* tömeges Seterra-eredménylista beillesztése és feldolgozása;
* egyéni eredmény kiszámítása;
* a Seterra-idő helyes, hagyományos kerekítése egész másodpercre;
* részletes, rendezhető eredménytábla;
* hibás vagy hiányos bemenetek egyértelmű jelzése;
* valódi, szűrhető és rendezhető Excel (`.xlsx`) export;
* magyar nyelvű, mobilon és asztali gépen is használható felület.

Az alkalmazás nem ad automatikus érdemjegyet: a korrigált százalékos eredményt számítja ki, a jegyhatárokat a tanár határozhatja meg.

Az alkalmazás nem igényel regisztrációt, bejelentkezést vagy szerveroldali adattárolást; az adatok csak az aktuális böngészőmunkamenetben kerülnek feldolgozásra.
